## 2. Saturation

Expect held-out or added categories to add types; the evidence-quality types look stable.

## 4. Proposed deterministic assertions

Variant column: B = baseline (no sources, `sources: []`), G = later retrieval-grounded variant (numbered `sources` list, answer cites `[n]`). Category gating uses the record's `category`.

For the baseline, A1/A2/A3 fail by construction whenever the answer makes a citation-shaped or numeric claim; their value there is to count fabrication, not to discriminate.

## 5. Limits

- Agent coder: coding was done by an AI agent from the same model family that will build and judge later steps, so shared blind spots are likely (for example, under-flagging plausible-sounding generic claims).
- Single coder, single pass: no inter-rater agreement; type boundaries (F1 vs F2, F5 vs partial verdicts) were set by one reader.
- 20 dev traces only: categories have 2-8 items each, so per-category counts (2/3, 2/3) are anecdotal. Held-out traces were deliberately not read.
- Citation fabrication was judged as "unverifiable from supplied sources", not checked against external indexes (no network). Some named cites (e.g., author surnames) may correspond to real people or papers; the claim here is only that the system gave no verifiable source.
- `expected_behaviour` strings are short; pass/partial/fail verdicts interpret them.
